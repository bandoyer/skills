# Continuing or transferring work

Use the current session while it can carry the task coherently. Keep accepted decisions, source references, and the remaining allowance in durable artifacts so compaction can preserve them.

| Situation | Useful action |
| --- | --- |
| The next step relies on current context | Continue |
| Context is nearing its actual limit | Preserve current state and use the harness's compaction support |
| Another session, workspace, or person must continue | Write a concise handoff with scope, approvals, evidence, and next action |
| A bounded independent task would benefit from delegation | Delegate only within the selected workflow and authorized cost |
| Starting unrelated work | Start a new task; preserve unfinished work first |

There is no universal token threshold or requirement to clear context between tickets. A transfer, compaction, or new reviewer does not reset scope, approvals, or the review allowance. Refer to the underlying evidence when a summary leaves a material question unresolved.
