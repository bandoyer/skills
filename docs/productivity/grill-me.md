## What it does

`grill-me` runs a focused interview to stress-test a plan or decision. It keeps the discussion in the conversation without automatically creating domain documents.

## When to reach for it

Invoke `/grill-me` when you want an interview. Use [grill-with-docs](https://github.com/bandoyer/skills/blob/main/docs/engineering/grill-with-docs.md) when you also want project terminology and decisions recorded.

## Common questions

**Do I have to answer every implementation detail?**

No. The shared interview method asks material questions and carries routine choices as stated assumptions.

**Will it start building afterward?**

Only if implementation was already requested and no reserved checkpoint remains. An interview-only request ends with its findings.

## It's working if

- Questions help settle the requested decision.
- Recommendations make the tradeoffs clear.
- The discussion stops when the outcome is actionable.

## Where it fits

It is an explicit entry point to [grilling](https://github.com/bandoyer/skills/blob/main/docs/productivity/grilling.md). [ask-matt](https://github.com/bandoyer/skills/blob/main/docs/engineering/ask-matt.md) helps choose a workflow.
